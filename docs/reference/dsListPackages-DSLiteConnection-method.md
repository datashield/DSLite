# List packages

List packages defined in the DataSHIELD configuration.

## Usage

``` r
# S4 method for class 'DSLiteConnection'
dsListPackages(conn)
```

## Arguments

- conn:

  [`DSLiteConnection`](https://datashield.github.io/DSLite/reference/DSLiteConnection-class.md)
  class object

## Value

A data frame.
