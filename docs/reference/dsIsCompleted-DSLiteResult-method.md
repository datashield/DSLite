# Get whether the operation is completed

Always TRUE because of synchronous operations.

## Usage

``` r
# S4 method for class 'DSLiteResult'
dsIsCompleted(res)
```

## Arguments

- res:

  [`DSLiteResult`](https://datashield.github.io/DSLite/reference/DSLiteResult-class.md)
  object.

## Value

Always TRUE.
