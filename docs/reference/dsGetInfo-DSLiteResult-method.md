# Get result info

Get the information about a command (if still available).

## Usage

``` r
# S4 method for class 'DSLiteResult'
dsGetInfo(dsObj, ...)
```

## Arguments

- dsObj:

  [`DSLiteResult`](https://datashield.github.io/DSLite/reference/DSLiteResult-class.md)
  class object

- ...:

  Unused, needed for compatibility with generic.

## Value

The result information, including its status.
