# List R symbols

List symbols living in the DataSHIELD R session.

## Usage

``` r
# S4 method for class 'DSLiteConnection'
dsListSymbols(conn)
```

## Arguments

- conn:

  [`DSLiteConnection`](https://datashield.github.io/DSLite/reference/DSLiteConnection-class.md)
  class object

## Value

A character vector.
