# DSLite asynchronous support

No asynchronicity on any DataSHIELD operations.

## Usage

``` r
# S4 method for class 'DSLiteConnection'
dsIsAsync(conn)
```

## Arguments

- conn:

  [`DSLiteConnection`](https://datashield.github.io/DSLite/reference/DSLiteConnection-class.md)
  class object

## Value

The named list of logicals detailing the asynchronicity support.
