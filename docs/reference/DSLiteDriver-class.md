# Class DSLiteDriver with constructor DSLite.

An DSLite driver implementing the DataSHIELD Interface (DSI)
[`DSDriver-class`](https://datashield.github.io/DSI/reference/DSDriver-class.html).
This class should always be initialized with the
[`DSLite`](https://datashield.github.io/DSLite/reference/DSLite.md)
function. It returns a singleton that allows you to connect to DSlite.
