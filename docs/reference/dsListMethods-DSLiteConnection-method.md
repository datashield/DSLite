# List methods

List methods defined in the DataSHIELD configuration.

## Usage

``` r
# S4 method for class 'DSLiteConnection'
dsListMethods(conn, type = "aggregate")
```

## Arguments

- conn:

  [`DSLiteConnection`](https://datashield.github.io/DSLite/reference/DSLiteConnection-class.md)
  class object

- type:

  Type of the method: "aggregate" (default) or "assign".

## Value

A data frame.
