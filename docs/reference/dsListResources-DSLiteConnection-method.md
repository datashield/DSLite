# List DSLite server resources

List resource names living in the DSLite server for performing
DataSHIELD operations.

## Usage

``` r
# S4 method for class 'DSLiteConnection'
dsListResources(conn)
```

## Arguments

- conn:

  [`DSLiteConnection`](https://datashield.github.io/DSLite/reference/DSLiteConnection-class.md)
  class object

## Value

The fully qualified names of the resources.
